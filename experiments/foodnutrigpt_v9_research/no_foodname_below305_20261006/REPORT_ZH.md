# 无 food name 单模型：187 轴 MAE 降至 0.305 以下

## 结论

目标已经达到。最终版本 **v33** 在统一 187 轴内部验证集上的 macro scaled-log MAE 为 **0.303675**，低于目标 **0.305**。相对固定母模型 v18 的 0.309882，绝对下降 **0.006207**，相对改善 **2.00%**。

v33 保留一个 Transformer，不使用 food name、来源、家族类别、教师模型、蒸馏或模型集成。Transformer 的层数、宽度、注意力头、dropout、FFN 宽度、学习率、batch size、优化器、训练数据、损失、随机种子和 20 epoch 训练过程均与 v18 相同。唯一新增结构是一个**训练集拟合的、逐轴有界收缩读出层**；它没有增加可训练神经网络参数，部署参数量仍为 2,057,125。

v33 超过了本轮数值门槛，也超过 KNN，但仍落后于 XGBoost 和 RF。因此，本轮证明了单 Transformer 可以在当前验证协议下降到 0.305 以下，没有证明 Transformer 已经成为总体最优方法。

## v33 的结构与原理

### 1. v18 先给出基础预测

对目标轴 `a`，v18 从该目标的 axis token 解码出 scaled-log 空间中的基础预测 `p(i,a)`。目标值和输入值都不包含 food name。

### 2. 只用训练集建立轴先验

对每个轴计算训练集 transformed target 的中位数：

```text
m(a) = median_train z(i,a)
```

这里的中位数只提供该轴的稳健中心，不读取验证标签。

### 3. 只用训练任务拟合逐轴保留率

最终输出被限制为基础预测与训练轴先验之间的凸组合：

```text
p'(i,a) = m(a) + alpha(a) * (p(i,a) - m(a))
0 <= alpha(a) <= 1
```

- `alpha=1`：完全保留 Transformer 预测。
- `alpha=0`：完全退回训练轴中位数。
- `0<alpha<1`：保留样本差异，同时压缩过大的预测偏移。

每个 `alpha(a)` 用该轴的训练预测和训练标签，直接最小化加权 L1：

```text
min_alpha sum_i w(i,a) * |m(a) + alpha * (p(i,a)-m(a)) - z(i,a)|
```

它有精确解：令 `r=(z-m)/(p-m)`，取 `r` 的加权中位数，权重为 `w*|p-m|`，再截断到 `[0,1]`。因此这里没有另训 RF、线性模型或第二个神经网络，也没有新增迭代优化超参数。

### 4. 为什么它仍是单模型

部署 artifact 只有一个 `TrainCalibratedShrinkageTransformer`。逐轴先验和保留率作为同一 checkpoint 的 buffer 保存，前向过程一次完成。它没有多模型投票、加权平均、teacher 输出或蒸馏损失。神经网络参数量与 v18 完全相同。

187 个监督轴的保留率统计如下：

| 统计量 | 保留率 |
| --- | ---: |
| 最小值 | 0.000000 |
| 25% 分位数 | 0.887236 |
| 中位数 | 0.945989 |
| 平均值 | 0.905938 |
| 75% 分位数 | 0.991271 |
| 最大值 | 1.000000 |

中位数接近 0.946，说明多数轴仍主要依赖 Transformer；收缩主要抑制部分轴上泛化较差的过度偏移。

这些结果说明：增加表达能力本身没有稳定收益。FiLM、直接关系残差、层融合和额外逐轴参数都可能提高训练自由度，但当前数据的难点更接近逐轴泛化方差。v33 对偏离训练轴中心的幅度施加了有数据依据的约束，而且不改变 Transformer 表征，因此比更复杂的端到端结构有效。

v32 与 v33 的差别尤其关键。v32 把收缩率和 Transformer 一起用训练梯度优化，最终平均保留率为 0.940323，187 轴误差为 0.311076。v33 先冻结已经完成的 v18，再用全部训练任务的预测误差解析拟合收缩率，平均保留率为 0.905938。分离表征学习与有界校准后，收缩强度更稳定，也不会被 Transformer 的其余参数吸收掉。

## 与三个传统基线的关系

- **RF**：每个轴一套 200 棵树的随机森林，输入为相同的数值加观测 mask。它在高覆盖的 142 轴切片上仍明显领先，所以总体第一。
- **XGBoost**：每轴 300 个 boosting rounds、深度 6、学习率 0.05。v33 与它的全轴差距缩小到 0.006480，但尚未追平。
- **KNN**：每轴在相同 504 维数值加 mask 空间取 16 个欧氏近邻并按距离加权。v33 比 KNN 低 0.041049。

v33 在 45 轴诊断切片上优于 RF 和 XGBoost，但 187 轴统一目标对每个轴等权；RF/XGBoost 在数量更多的 142 轴切片上的优势仍决定总体排序。

## 完整性与限制

- v33 的收缩参数只读取训练行的预测、标签和权重；验证标签没有参与拟合。
- v33 沿用 v18 第 20 轮 checkpoint；v18 的 20 行训练 history 原样保存。
- 187 个监督轴都有训练校准支持，共使用 1,828,536 个观测训练目标。
- 本轮新增的 13 组模型测试共 25 项，全部通过；manifest、代码 SHA-256、187 轴覆盖、20 行 history 和单模型标记另行复核通过。
- 仓库全量测试有 691 项通过；另有 10 项 setup error 和 1 项失败，原因都是本地缺少两个与本实验无关的 reference/processed 数据 artifact，不是本轮代码回归。
- 完整测试集没有打开；本报告全部结果都是内部验证结果。
- 当前结论来自一个随机种子。0.303675 比门槛低 0.001325，已经达到本轮目标，但仍应通过重复种子或 bootstrap 评估其稳定性。
- 多轮结构搜索都查看了同一内部验证集，因此 0.303675 适合用于当前研发选型，不应直接当作无偏最终泛化估计。下一次对外结论应在冻结结构后使用未打开的测试集或新的外部验证集。

## 最终选择

在当前约束下，保留 **v33** 作为新的最佳无 food name 单 Transformer：

1. 统一 187 轴主指标低于 0.305；
2. 固定 v18 的全部训练参数与 20 epoch checkpoint；
3. 不增加神经网络参数；
4. 不使用 food name、source、类别标签、模型集成或蒸馏；
5. 校准只使用训练数据，并同时改善两个诊断切片。
