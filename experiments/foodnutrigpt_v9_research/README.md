包括hurdle-loss选点复现在内的 [未完成确认项](OPEN_CHECKS.md) 单独跟踪；不能用已通过的局部测试代替这些要求。

[三种子确认协议与执行入口](CONFIRMATION.md) 已实现，加入R3独立头与诊断后52项相关研究测试通过。实际确认训练尚未完成；程序会拒绝重复种子、不同数据/输入或不同配置/代码的运行，不能以工具完成代替研究证据。

同seed20260922探索对照中较强XGBoost主指标0.173784，RF400为0.188480。MLP当前最低点估计为1024宽度的0.183054，仍比该XGBoost差5.33%、原log-MAE差9.93%；相对RF改善2.88%，但未满足5%门槛且原log-MAE退步2.70%。加宽相对512的补全改善区间跨零、name-only退步11.56%，因此保留512为后续受控比较的参照，不将最低点估计视为已接受改进。树模型其他种子的结果逐项记录在确认报告，不能挑较弱种子比较。MAE损失、容量、时长的收益机制及name-only/检索取舍分别记录，不把同时改变日程与时长的跨运行差异当作纯时长效应。所有原始数值、模型、缓存和完整预测留在本地被Git忽略的目录中，报告保留配置、哈希、汇总结果及因果边界。
