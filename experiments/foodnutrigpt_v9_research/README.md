# Nutrition representation model 研究记录

当前目标：在共同数据、输入、遮蔽和指标下，尝试使营养补全超过充分调参的RF/XGBoost；同时跟踪仅名称预测与营养到未见名称检索。当前尚未达到该目标，不宣称foundation model成立。

| 版本 | 状态 | 报告 |
|---|---|---|
| V9-R0 | 共同数据/评价及首轮基线探索已完成；原始标签证据未闭环 | [核验与基准](r0/README.md) |
| V9-R1 | 完整共同训练任务已核验；时长、amount、来源与更大树基线对照进行中 | [训练优化](r1/README.md) |
| V9-R2 | MAE损失单因素完成，加宽MLP单因素进行中；未确认 | [数值目标实验](r2/README.md) |

指标、数据隔离视图和验证面板已经冻结。历史测试集保持关闭。单种子探索、配对食品组区间和三种子确认分别记录；未达到确认门槛不写成确定结论。

当前已完成运行中较强XGBoost主指标0.178131；MLP从SmoothL1的0.222459改善到MAE的0.209484，仍落后17.60%。MAE改善显式零但损害正值预测，完整取舍见R2报告。所有原始数值、模型、缓存和完整预测留在本地被Git忽略的目录中，报告保留配置、哈希、汇总结果及因果边界。
