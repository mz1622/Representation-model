指标、数据隔离视图和验证面板已经冻结。历史测试集保持关闭。单种子探索、配对食品组区间和三种子确认分别记录；未达到确认门槛不写成确定结论。

包括hurdle-loss选点复现在内的 [未完成确认项](OPEN_CHECKS.md) 单独跟踪；不能用已通过的局部测试代替这些要求。

[三种子确认协议与执行入口](CONFIRMATION.md) 已实现，加入R3独立头与诊断后52项相关研究测试通过。实际确认训练尚未完成；程序会拒绝重复种子、不同数据/输入或不同配置/代码的运行，不能以工具完成代替研究证据。

当前已完成运行中较强XGBoost主指标0.173784，RF400为0.188480。MLP经损失、宽度和固定日程训练预算对照后达到0.184491，仍比XGBoost差6.16%、原log-MAE差11.10%；相对RF的主指标优势区间跨零且原log-MAE退步超过2%，不宣称胜出。MAE损失、容量、时长的收益机制及name-only/检索取舍分别记录，不把同时改变日程与时长的跨运行差异当作纯时长效应。所有原始数值、模型、缓存和完整预测留在本地被Git忽略的目录中，报告保留配置、哈希、汇总结果及因果边界。
