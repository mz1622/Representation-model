## 1. 研究问题与预先假设

R2延长训练改善补全，加宽512→1024进一步降低训练误差，但补全收益区间跨零、name-only明显退步。内部名称标准化也降低训练误差而没有补全收益。待验证的更具体假设是：在同样的512维上下文编码器后，逐轴纯线性输出可能限制数值关系表达；共享非线性轴查询读出可能改善未见食品的补全，尤其已有诊断中相对XGB较弱的正值。

若成立，应在固定验证面板看到补全主误差降低，正值可加误差贡献改善，并报告name-only和排序代价。更低训练误差或较早收敛不能单独支持假设；收益区间跨零时保留“证据不足”。首项登记时只做读出对照，其他训练目标须在其三任务结果之后另行登记。

首项结束后另登记第二项：只加入同一食品不同可见营养上下文的融合表征一致性，能否改善补全泛化？可证伪预期、相同计算控制、额外视图、固定权重与指标见 [PLAN_VIEWS.md](PLAN_VIEWS.md)，预登记`3ed3720`。两个名称相同的视图可能鼓励名称依赖或丢失上下文差异，因此C下降不是成功标准。

**已观察事实：** 固定单种子和预算下，新增共享非线性查询读出没有降低补全的训练/验证主误差；name-only和完整MRR只有不确定的点估计收益。它仍明确弱于XGB及名称专项基线。

**对照支持的解释：** 这项具体读出结构干预没有支持“仅增加轴查询非线性即可解决当前主要差距”的假设。保留原线性头作为后续控制更有依据。该结论限于这套初始化、参数规模、损失和日程，不能推断所有查询架构无效。

**未排除的替代解释：** 新残差和原头之间的优化分工、零初始化的学习过程、梯度裁剪耦合、AdamW正则化、种子及选点波动。共同初始函数一致并不控制全部优化轨迹；没有消融支持时，不把结果唯一归因于轴身份、容量或过拟合。所有候选使用同一反复查看的验证面板，探索区间不等于独立泛化验证。

**第二项已观察事实：** 在已核验相同视图/监督、原参数初始化和日程的控制下，增加系数0.1显著改变了表示几何、梯度裁剪频率及名称预测；补全主指标没有支持收益，排序区间均包含零。

**对照支持的解释：** 这项具体一致性目标有真实训练作用，但它不是“更小视图距离必然带来更好补全”的证据。名称收益主要来自正值，并有零值代价。两视图共享名称，因此更多依赖名称也是可能路径，不能自动解释为更好的独立营养表示。

**后续机制证据与边界：** 共同平移反事实已证实同一预测函数能有很不一样的单位化距离，但去均值后两个训练模型仍不同，不能把全部收益归为偏移或断言完全坍塌。两次早期异常均在未请求轴，已通过事前登记的共同查询契约区分接口语义；第三次异常发生在请求内无标签轴，证明当前中心化配置不能保证合法请求返回有限值。范数、裁剪和输出增长是伴随现象，不唯一证明批均值、梯度规模或语义丢失导致失败；也不证明有评分标签的轴必然发散。失败记录不被工程修正抹去。
