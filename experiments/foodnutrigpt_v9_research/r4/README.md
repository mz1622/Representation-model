# V9-R4：轴查询读出与食品表示（预登记）

**状态：父控制与一个新候选已登记，2/12项预算；尚未产生新训练结果。** 本版从已完成R2的原MAE/512/60模型开展单因素结构试验。R1–R3均已完成探索，未有超过强XGBoost的神经网络。本版不预设查询头有效，也不把接口可用称为表征迁移。

## 1. 研究问题与预先假设

R2延长训练改善补全，加宽512→1024进一步降低训练误差，但补全收益区间跨零、name-only明显退步。内部名称标准化也降低训练误差而没有补全收益。待验证的更具体假设是：在同样的512维上下文编码器后，逐轴纯线性输出可能限制数值关系表达；共享非线性轴查询读出可能改善未见食品的补全，尤其已有诊断中相对XGB较弱的正值。

若成立，应在固定验证面板看到补全主误差降低，正值可加误差贡献改善，并报告name-only和排序代价。更低训练误差或较早收敛不能单独支持假设；收益区间跨零时保留“证据不足”。完成三任务评价后才决定下一项，暂不登记一致性损失、对比学习、任务比例或更大编码器。

## 2. 父版本与唯一改动

父控制固定 `output/v9_r2/mlp60_mae_width512`，使用含LayerNorm的两层512维共享MLP、MAE、0%额外name-only、原PCA32输入、不作名称标准化。新候选从头训练，**没有加载父模型训练完成的权重**；共同父参数的初始化一致。

唯一结构改动是在原252轴线性头上加 `AxisQueryResidual`：上下文512→128，离散轴嵌入32，联合128维GELU和标量输出。最后层全零初始化，参数由667,900增至762,365。每个查询独立读同一表示，查询集合不参与上下文编码；不依据真实标签的存在性决定查询。65个context-only轴仍不宣称可靠预测，不支持新营养轴零样本语义。

零初始残差保留父预测和共同参数裁剪前梯度，但全局clip1包含新增梯度，AdamW衰减也影响内部权重；首步父参数更新、后续优化轨迹并非保证相同。容量、共享结构和优化几何是这次干预的一部分，不能唯一归因于“轴语义”或声称参数量匹配。

数据、尺度、划分、337,048个家族任务、每轮1,828,536个已观测监督、来源/轴权重、187轴损失和142轴选点均保持不变。batch256、lr0.001、AdamW wd0.0001、clip1、60轮cosine至0.00001、seed20260922固定，无提前停止。树模型输入、任务与指标未变，可以复用已核验同协议基准；不为了新结构削弱树或更换主指标。
