# 无 food name：统一 187 轴目标复跑报告

## 结论

本轮把 187 个监督轴作为唯一训练与选模目标。模型不接收 food name、食物 ID、来源 ID，也不接收 nutrition/metabolome 类别标签。142/45 分组只作为训练完成后的诊断切片，不参与损失、checkpoint 选择或模型结构。

在同一完整验证协议下，RF 的 187 轴 scaled-log MAE 最低，为 **0.286841**；XGBoost 第二，为 **0.297195**；Transformer 中 v18 最好，为 **0.309882**。v18 比 v16 改善 3.08%，比 KNN 改善 10.11%，但仍比 RF 高 8.03%、比 XGBoost 高 4.27%。因此，当前统一目标下的排序仍是 **RF > XGBoost > v18 > v16 > v3 > v7 > KNN**。

v18 首次在保存下来的正式 checkpoint 上低于预先讨论的 0.31 目标，但只低 **0.000118**，且只有一个随机种子和内部验证集，应该视为刚刚达到数值门槛，不能视为稳定超过门槛。

## 统一实验协议

| 项目 | 本轮设置 |
| --- | --- |
| 数据 | `foodnutrigpt_v9_r0_v1` quarantined 数值视图 |
| 训练/验证记录 | 64,700 / 11,175 |
| 验证任务 | 323,809 个 profile-axis 任务 |
| 目标轴 | 187 个统一 composition axes |
| 输入 | 可见 axis ID、连续数值、目标 axis token；不含 food name、食物 ID、来源 ID或类别标签 |
| 数值变换 | 每轴训练集正值中位数尺度；`z = log1p(raw / scale_axis)` |
| 遮蔽 | 按既有依赖家族遮蔽，目标家族数值不可见 |
| 神经模型损失 | 对 187 个轴逐轴归一后宏平均的绝对误差 |
| 主指标 | 187 轴 macro scaled-log MAE，越低越好 |
| checkpoint | 20 轮全部训练完成后，选择 187 轴主指标最低的轮次 |
| 随机种子 | 20261005 |
| 测试集 | 未打开，`complete_test_opened=false` |

RF、XGBoost 和 KNN 没有神经网络式 epoch。它们各自在完整训练集上完成一次固定拟合；XGBoost 的 300 棵提升树是 boosting rounds，不是 20 个 Transformer epoch。v3、v7、v16、v18 均严格训练 20 epochs。

## 三个传统基线的技术配置

三种基线都逐目标轴独立拟合。输入是 504 维固定向量：252 个可见轴的变换后数值，加 252 个观测掩码。缺失或被遮蔽位置的数值槽填 0、掩码为 0；真实观测零值的数值槽也是 0，但掩码为 1，所以缺失与真实零不会混淆。目标轴所属家族在训练和验证时都被遮蔽。

### RF

- 每个目标轴训练一套 `RandomForestRegressor`，共 187 套回归器。
- 每套 200 棵回归树，bootstrap 抽样。
- 分裂准则为 squared error；每次分裂随机考虑 50% 特征。
- 叶节点最少 2 条样本，不限制最大深度。
- 每轴随机种子为 `20261005 + axis_id`。
- 多棵树预测取平均；拟合使用 4 线程，最终预测使用固定树顺序。

RF 的优势来自分段规则和树集合：它能直接学习“某些轴存在、另一些轴落在某个数值范围时，目标值通常是多少”，不要求关系是线性的，也不需要共同优化 187 个任务。

### XGBoost

- 每个目标轴训练一套 `XGBRegressor`。
- 每套 300 个 boosting rounds，最大深度 6，学习率 0.05。
- `min_child_weight=5`、行采样 0.8、列采样 0.8、L2 正则 1。
- 使用 `hist` 建树和 squared-error 回归目标，4 线程。
- 后一棵树拟合前面树留下的残差，所有树的输出相加得到目标 `z`。

XGBoost 比 RF 更强调逐步纠错。本轮它比 RF 高 0.010355，但仍比所有 Transformer 更好。

### KNN

- 每个目标轴只在该轴有训练标签的记录中建立近邻索引。
- 使用完整 504 维输入的欧氏距离，取最近 16 个邻居。
- 按 `1 / (distance + 0.001)` 加权邻居的目标 `z`。
- 没有可学习参数、树或 epoch；预测完全由局部相似记录决定。

KNN 的全轴误差最高，说明在高维、稀疏、缺失模式复杂的组成空间里，单纯依赖欧氏近邻不够稳定。

## Transformer 架构

| 模型 | 核心结构 | 宽度/头/层 | FFN | 注意力 |
| --- | --- | --- | --- | --- |
| v3 | 目标 axis token 保留身份，遮蔽数值；从该 token 解码一个标量 | 128 / 4 / 2 | GELU，宽 256 | 标准 self-attention |
| v7 | 在 v3 上替换编码器 FFN | 128 / 4 / 2 | 参数量匹配的 ReGLU | 标准 self-attention |
| v16 | 在 v7 上加入每个有序 axis pair、每个 head 的可学习 attention-logit bias | 128 / 4 / 2 | ReGLU | axis-pair bias |
| v18 | 扩大 v16 容量 | 192 / 6 / 3 | ReGLU，宽 256 | axis-pair bias |

四个模型都使用 AdamW、学习率 `3e-4`、weight decay `1e-4`、batch size 128、梯度范数上限 1。v3/v7/v16 dropout 为 0.10；v18 按用户指定为 0.15。

本轮 v7 没有复现此前相对 v3 的优势。v3/v7 使用标准 CUDA multi-head attention，在固定 seed 下仍可能出现非逐位确定的运行差异；因此不能依据这一颗重跑种子得出“ReGLU 必然更差”的结论。v16、v18 的新旧训练轨迹逐轮一致，统一选模本身没有改变训练过程。

## 142/45 诊断切片

以下分组不参与选模，仅用于解释统一分数。

| 方法 | 142轴诊断 | 45轴诊断 | 187轴主指标 |
| --- | ---: | ---: | ---: |
| RF | **0.178649** | 0.628245 | **0.286841** |
| XGBoost | 0.190612 | 0.633525 | 0.297195 |
| KNN | 0.239212 | 0.677675 | 0.344725 |
| v3 | 0.246676 | **0.568266** | 0.324064 |
| v7 | 0.240426 | 0.612440 | 0.329948 |
| v16 | 0.231242 | 0.598959 | 0.319730 |
| v18 | 0.225631 | 0.575741 | **0.309882** |

RF 的总体优势主要来自 142 个高覆盖轴；v18 在 45 轴诊断切片上比 RF 低 8.36%。逐轴比较中，v18 在 45 个诊断轴里有 25 个优于 RF，而在另外 142 个轴里只有 15 个优于 RF。由于统一目标对每个轴等权，RF 最终仍然领先。

在七种方法中逐轴选择最低误差者，RF 在 96 个轴上最好，XGBoost 43 个，KNN 6 个，v3 9 个，v7 10 个，v16 10 个，v18 13 个。这只是描述性分析，不能据此在验证集上拼接一个新模型。

## 对旧选模结果的影响

- v16 的统一最优轮次仍是第 18 轮，所以结果与旧 checkpoint 完全相同。
- v18 从旧的第 18 轮改为第 20 轮，187 轴误差从 0.322537 降至 0.309882。旧规则选择的是 142 轴最优点，确实错过了整体更好的 checkpoint。
- v3 从旧的第 18 轮改为本次第 16 轮；由于标准 CUDA attention 的非逐位确定性，本次是一次完整新运行，不能把全部差异只归因于选模规则。
- v7 本次和旧运行都选择第 16 轮，但两次点估计不同；这同样提示单种子、非严格确定性运行不足以支持很小的结构差异。

## 运行完整性

- 五项正式运行均为 `status=complete`，覆盖 187 个轴和全部 323,809 个验证任务。
- v3、v7、v16、v18 的 history 均恰好包含 20 行。
- 固定完整测试集未打开。
- 第一次 v16 进程因会话中断停在第 7 轮，已标记 `interrupted`，没有生成或参与任何最终指标；报告使用完整重跑目录 `no_foodname_v16_unified187_20ep_retry1_20261006`。
- 代码检查通过：相关 10 项测试全部通过。

## 最终判断

1. **统一 187 轴选模是正确的。**v18 的结果直接证明，按 142 轴选点会错过整体更好的 checkpoint。
2. **当前最强统一模型仍是 RF。**Transformer 尚未在 187 轴主指标上追平 RF 或 XGBoost。
3. **v18 是当前最好的单 Transformer。**它达到 0.309882，并在 115/187 个轴上优于 v16。
4. **axis-pair bias 与容量增加值得保留。**从 v7 到 v16、再到 v18，统一主指标连续改善。
5. **下一步不应继续依据单次小差异改结构。**优先对 RF、XGBoost、v16、v18做相同协议的多种子或 bootstrap 不确定性分析，再决定是否投入新的结构搜索。
