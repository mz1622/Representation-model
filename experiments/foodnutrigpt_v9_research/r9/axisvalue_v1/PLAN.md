# R9 第4/12个方法候选：零初始化营养轴×数值残差

此登记在候选训练前建立。父模型是种子20260922的 `tf192_mae_lr3e4_60`，不微调其检查点。MSE单因素筛选已经完成且被拒绝，三个MAE种子也未满足优于冻结RF的确认条件。

## 研究假设与可否定预测

现有数值token是 `e_axis + g(t)`，其中g为所有轴共享的两层数值MLP，t为冻结的训练尺度变换值。注意力可学习交互，但轴和数值之间没有直接的乘积参数。本轮检验增加轴专属线性斜率是否改善相同数值在不同营养轴上的条件表示，尤其是补全所需的营养间关系。

只增加 `t * r_axis`，得到 `e_axis + g(t) + t*r_axis`。r为252×192的可训练参数，全部零初始化，不消耗额外随机数。缺失及被遮蔽值不贡献该残差，显式零仍有轴标识及可见状态。初始旧参数、CPU/CUDA随机状态、eval及带dropout的train前向须与父模型精确一致。来源仅用于训练损失校准，不进入编码器。

若假设有帮助，整体补全主误差应下降，并检查氨基酸、脂肪酸及正/零误差；这些分组只作解释，不替换主指标。如果拟合提高但验证不提高，或辅助任务/旧log明显退步，则拒绝此配方。增加48,384个参数也是容量变化；即便成功，也不能唯一归因于轴交互，需要后续等容量控制。

特征专属数值向量的参考是[Revisiting Deep Learning Models for Tabular Data](https://arxiv.org/html/2106.11959v5)及其[官方tokenizer实现](https://github.com/yandex-research/rtdl/blob/main/rtdl/modules.py)。本轮保留原模型，仅添加零初始化残差，不是完整FT-Transformer复现，也不借用其成绩作证据。

## 控制和训练

保持MAE、192维、3层、6头、FF768、dropout0.15、rank16、来源损失权重1、来源L2=1e-4、batch64、AdamW lr3e-4/weight decay1e-4、clip1和60轮余弦调度。主损失仍为 `(L_base + L_calibrated)/2 + 1e-4*mean(R_train^2)`。没有新采样、训练阶段或text-only任务比例。

从头同种子初始化；每轮337,048个既定家族任务、1,828,536个目标，顺序仍由seed+epoch生成。全部67项冻结数据/缓存/任务/树产物指纹须一致。不增加数据变换或轴语义信息；文本仍是原名PCA32加零填充至128维。原始V8、研究视图、尺度、标签聚合、mask、分母、查询规则和来源权重均不改。RF/XGB/KNN只复用已保存预测，不重新拟合。

功能检查使用合成输入及训练行：零初值/旧参数/RNG/前向一致；非零残差对可见值有作用，对隐藏值和来源变化不敏感；未观测监督轴可查询；缺失不进损失，显式零有梯度；name-only只含名称；营养encode不含名称；新公共加载器重载精确且encode使用同一新token路径。先用32个训练任务做50步小批过拟合，再完整重置参数和CPU/CUDA RNG后正式训练。NaN/Inf立即失败。

## 评价与预先决定规则

142轴scaled-log MAE按同一完整验证面板选最早严格最小轮次；保留60轮轨迹及前20轮最优快照。所有三任务使用同一补全检查点。报告142/45/187轴、旧log/原始单位、正/零、逐轴/来源支持、名称任务和固定49,913候选名称检索。测试保持关闭。

完整独立重放后，与同种子MAE、冻结RF和XGB作三任务比较，与冻结KNN作name-only/检索比较，共11项；食品组配对重采样1000次。正式筛选条件全部须满足：相对同种子MAE主误差更低，配对改善区间下界>0，旧log-MAE相对退步≤2%。分组收益或一个辅助任务收益不能替代筛选。

筛选通过后，另外登记同配方20260923/20260924复验；接受改进须三种子，最终RF目标还要求三种子均值主指标优于冻结RF、食品组配对区间支持改善、旧log退步≤2%。没有5%最低改善要求，不要求超过XGB。不把选中最好种子或不同任务最好模型拼成一个模型。

预计单GPU训练约3小时，实际记录成本；保持每轮48–72小时预算，最多12个方法配方。本候选是第4个，非新一轮树搜索。训练结束前不根据早期曲线改配置。失败保留原因；若另试学习率、正则或数值编码，则另登记候选。
