## 6. 因果分析

事实：全日程2/3干预后，整体训练和多数常见轴改善，主验证指标未可靠改善、旧log点退步超过门槛、名称主指标退步。受控解释：该固定配方不适合作为当前补全升级。不能推出较低学习率普遍有害、所有轴过拟合或稀疏曝光不足。

未排除因素：GPU非确定性、不同优化轨迹和随学习率变化的AdamW衰减、单种子、验证选择、多来源构成与标签问题。训练/验证食品支持不同，较大拟合间隙仅提出正则化假设，不证明机制。数据和评分保持冻结。
