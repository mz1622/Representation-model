# V9-R7：名称压缩实验（探索完成，保留高维输入方向）

六项登记预算全部完成，含两个历史参照和四个新配置。匹配32→128后，名称MLP主指标改善8.84%，KNN改善6.87%；同128输入MLP仍比KNN差5.11%。因此保留“增加名称信息”进入补全实验，**不接受神经模型已超过强基线的结论**。本轮没有改变主补全模型，也没有完成全项目目标。

## 1. 研究问题与预先假设

R6额外上下文删除损害固定补全任务；训练名称几何诊断显示原PCA32可能丢失信息。假设更多名称方向会改善名称→营养及由预测档案进行的反向检索。[预登记](PLAN.md)提交`88180c1`先于结果，筛选标准为名称主指标至少1%改善且食品组区间支持；筛选不是三种子确认。旧测试关闭。

## 2. 父版本与改动

原名称向量来自固定MiniLM384维、仅original_name。仅使用64700个训练档案拟合float64精确PCA128，保持原重复档案权重，无白化/额外标准化。32控制取同一基底前32方向，排除求解器差异；两缓存共享128槽位，32控制其余96列为零。实际保留方差分别54.533%/87.846%，不把方差本身当营养收益。

MLP两臂均width256、LayerNorm、164092参数，相同初始化、60epoch、全64681合格训练档案/1828536目标、batch256、原187轴批内归一MAE、AdamW lr.001/wd.0001、clip1、cosine60。固定142营养主指标选点。KNN固定10邻居、KDTree、全合格训练行、原来源权重及inverse-distance加权缩放log均值，分别使用32/128有效方向；不做k调参。所有方法沿用相同R0标签、尺度、验证任务与评分权重。

旧随机PCA32 KNN用于数值实现参照；旧名称MAE MLP只有139516参数/32输入，不能参与“只改维度”的严格归因。新输入与旧RF/XGB不同，不能直接宣布补全超越旧树。本轮四个模型都只根据名称预测营养，补全栏是忽略数值上下文的名称基线，不是已训练数值编码器的能力。

## 6. 因果分析与替代解释

**观察事实：** 同一标签/评分下，增加有效名称方向对两类模型的名称营养预测有食品组区间支持的收益；同128输入KNN仍胜名称MLP。单一模型三个任务分别报告，没有拼接三个模型的最好分数。

**对照支持的解释：** 同基底前缀、固定模型参数/初始化/训练日程和同一KNN规则，支持“原名称压缩限制了一部分可用预测信息”这一局部解释。旧PCA32→精确PCA32 KNN差异很小且区间跨零，不能把128收益全归给PCA求解器。收益主要出现在正值及较充分观测轴。

**仍未排除：** 只有一个神经种子；额外信息与可利用连接数的变化不能完全分离；MAE神经目标与邻居加权均值不同，尚无目标匹配消融证明正值/零值取舍成因。缓存仍是冻结通用语言模型、未做营养特定文本编码器训练。验证反复选择与别名/转载关系可能影响结果；单位证据未闭环。不据此声称nutrition foundation model或外部迁移能力已成立。

## 7. 版本决定

关闭六项配置的探索，保留所有结果与失败记录。两种方法均通过预登记名称维度筛选；**保留128维输入研究分支，未接受名称MLP超过强基线，也未宣称补全5%里程碑已达成**。不为耗尽12项上限继续随机试维度。R5完整营养输入检索专用模型的三种子支持是另一个限定能力，不能拼入本轮模型。

新增缓存视图独立命名，旧32输入RF/XGB及旧结果不改。下一轮必须同新输入重跑并给树明确全数据调参预算；最终接受仍需三个固定种子及食品组区间。原始V8不变，原始单位溯源尚待证据，全部结论限定为当前隔离研究视图。
