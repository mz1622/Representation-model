# 无 food name 的 scGPT 对齐补全：masked axis token 三种子报告

## 结论摘要

本轮把补全责任从 `[FOOD]` 汇总 token 转移到被遮蔽的目标 axis token。数据、训练/验证划分、现有成分家族遮蔽、数值尺度、损失、训练预算和三个传统基线均未改变；food name、食物 ID 和来源 ID 仍不进入模型。完整测试集未打开。

新的 masked-axis Transformer 在三颗种子上的营养 142 轴 scaled log MAE 为 **0.239093 ± 0.004037**，全部 187 轴为 **0.326706 ± 0.002674**。相对旧 `[FOOD] → 252轴` 单种子控制的 0.243857 / 0.339431，点估计分别改善 1.95% / 3.75%；相同种子 `20261005` 的直接比较中，营养轴基本持平，全部轴改善 3.89%。主要收益来自食品代谢物轴。

该改变没有追上 RF：RF 的营养/全部轴误差为 **0.178649 / 0.286841**。新的 Transformer 三种子均值仍分别高 33.8% / 13.9%。因此，axis-token 补全是更合适的正式 Transformer control，但当前证据仍支持 RF 是营养和全轴补全的最强基线。

## 架构改变

旧控制模型的序列只有 `[FOOD]` 和可见 `(轴 ID, 数值)` token。Transformer 编码后读取 `[FOOD]`，再通过一个 252 维线性头同时预测所有轴。所有补全误差都直接要求 `[FOOD]` 承担预测。

新模型沿用 scGPT 的 gene-expression prediction 角色分工：保留目标轴身份，只遮住目标数值。

```text
[FOOD]
+ 可见轴 embedding + 数值 MLP(value)
+ 目标轴 embedding + [MASK_VALUE]
        ↓
  2 层无位置编码 Transformer
        ↓
目标 axis token 的最终隐藏状态
        ↓
所有轴共享的标量数值解码器
```

`[FOOD]` 仍参与双向注意力并可导出食物整体表示，但不连接全轴预测头。共享解码器按照 scGPT `ExprDecoder` 的形状使用 `Linear(128,128) → LeakyReLU → Linear(128,128) → LeakyReLU → Linear(128,1)`。目标 token 使用与可见 token 相同的 axis embedding，因此预测“钙”和预测“铁”拥有明确、不同的目标身份。

为防止标签存在性泄漏，每个现有遮蔽任务都加入该任务中固定的全部可监督目标轴，是否有真实标签只决定该位置是否计算损失。没有根据单条记录中哪个轴实际被测量来决定是否加入目标 token。本轮没有重新设计或调整成分家族。

## 固定训练协议

| 项目 | 设置 |
| --- | --- |
| 输入 | 可见轴 ID、可见连续 `z` 值、固定目标 axis token；无 food name、来源或食物 ID |
| 编码器 | 2 层，维度 128，4 个注意力头，前馈维度 256，dropout 0.1 |
| 数值编码 | `Linear(1,128) → GELU → Linear(128,128)` |
| 目标值 | 训练正值中位数尺度下的 `z=log1p(raw/s_a)` |
| 损失 | 187 个监督轴宏平均绝对误差，只在实际观测标签上计算 |
| 优化 | AdamW，学习率 `3e-4`，weight decay `1e-4`，batch 128，梯度范数上限 1 |
| 训练与选点 | 固定 20 轮；每轮验证；按营养 142 轴 scaled log MAE 选点 |
| 种子 | `20261005`、`20261006`、`20261007` |
| 参数量 | 347,649；旧控制为 346,876 |

新旧模型参数量只差 773，因而本轮不是简单增加容量。三个运行的最佳检查点均为第 18 轮，说明结果不是用不同早停阶段拼出的比较。

## 三种子结果

主指标均为 scaled log MAE，越低越好。`±` 是三颗种子的样本标准差。旧 Transformer 和传统基线沿用已经完成的冻结验证结果。

| 方法 | 营养 142轴 | 食品代谢物 45轴 | 全部 187轴 | 全轴原单位 MAE |
| --- | ---: | ---: | ---: | ---: |
| Masked-axis，种子 20261005 | 0.243748 | 0.586440 | 0.326214 | 0.357129 |
| Masked-axis，种子 20261006 | 0.236557 | 0.601224 | 0.324312 | 0.379397 |
| Masked-axis，种子 20261007 | 0.236973 | 0.621853 | 0.329591 | 0.368184 |
| **Masked-axis，均值±SD** | **0.239093±0.004037** | **0.603173±0.017787** | **0.326706±0.002674** | **0.368237±0.011134** |
| 旧 `[FOOD] → 252轴`，种子 20261005 | 0.243857 | 0.641018 | 0.339431 | 0.399917 |
| RF | **0.178649** | 0.628245 | **0.286841** | **0.249069** |
| XGBoost | 0.190612 | 0.633525 | 0.297195 | 0.259064 |
| KNN | 0.239212 | 0.677675 | 0.344725 | 0.374410 |

相同种子 `20261005` 下，新结构相对旧控制：营养误差降低 0.000110，基本持平；代谢物误差降低 0.054578；全轴误差降低 0.013217。逐轴看有 128/187 轴改善。按三种子均值对旧控制比较，有 124/187 轴改善，其中 92 个营养轴、32 个代谢物轴改善；92 个轴在三颗新种子中都优于旧控制的固定结果。

三种子宏平均逐轴 log RMSE 为 **0.584787±0.001965**，旧控制为 0.588115，改善仅 0.57%；RF 为 0.464879。这说明 masked-axis 主要改善平均绝对误差，对较大误差尾部的帮助较小。

## 怎样解释结果

1. **目标 axis token 是更合理的补全接口。**它用几乎相同参数量稳定改善全轴点估计，且让目标身份进入 Transformer 的每层注意力，而不是要求 `[FOOD]` 一次承担全部输出。
2. **营养轴没有出现同等幅度的改善。**三种子均值略好于旧单种子控制，但相同种子的差异几乎为零；不能把 1.95% 的非对称均值比较当成已确认的营养收益。
3. **食品代谢物轴收益更明显但仍有种子波动。**三颗种子均低于旧控制和冻结 RF 的点估计，均值为 0.603173；样本标准差 0.017787。该观察值得保留，但检查点按营养指标选择，且没有独立外部数据确认。
4. **这次改变没有消除 RF 优势。**RF 在营养与全轴主指标、原单位 MAE和 log RMSE上仍明显领先。新 Transformer 不能替换 RF 作为统一基线。

## 完整性与限制

- 三个完整运行均使用数据清单 SHA-256 `48aa0b22a816cc175c8d274628a747ca44a90339bda46d33aada7cee9ea9d923`，状态为 `complete`，`complete_test_opened=false`。
- 7 项测试通过，覆盖名称不进入输入、目标 query grid 不依赖标签存在性、目标真值不进入输入、明确零与缺失区分、可见和目标 token 的排列性质、padding 与空上下文处理。
- 当前结论只覆盖冻结内部验证划分，没有独立外部验证。接入外部数据时必须沿用训练轴映射和训练尺度，由调用者明确给出待补全目标轴，程序再加入 `[MASK_VALUE]`。
- 新模型有三颗种子，旧无名称控制只有一颗种子；结构收益的三种子对三种子配对确认尚未完成。因此报告保留同种子比较与非对称均值比较，不宣称已完成严格的结构因果确认。
- 本轮按用户要求没有重新处理成分家族、派生指标依赖或家族遮蔽合理性。
