# V9-R1 预登记：共同训练任务与现有模型的优化

目标保持不变：在公平比较下尝试使营养预测超过 RF/XGBoost。R0 结果表明 V9 的差距不是单纯评分标签聚合造成的，但训练遮蔽任务并不一致。

本轮固定 R0 隔离数据、全部187监督轴、142营养轴主指标、原名32维特征和验证面板。单位原始证据仍未闭环；本轮仅对该冻结视图做受控优化，不据此宣称外部营养标签可信或基础模型成立。

## 协议修复

建立完整训练家族任务：337,048 个档案×家族任务覆盖1,828,536个观察到的目标单元，每个目标每轮出现一次。所有家族关联轴都隐藏，包括context-only形式。逐家族穷举核对树模型的训练行、标签、有效输入和原始来源权重，并保留哈希凭据。缺失值不监督、零值监督、全部查询轴固定。

神经网络改用完整数据集的逐轴来源权重归一化，使每个小批量损失是完整逐轴宏平均目标的无偏估计。R0→R1同时修复训练输入分布与损失估计，因此不能把两版本差异归因于一个因素。R1内部的后续对照只改变指定因素。

树模型的原始逐轴训练样本和验证面板不变；穷举契约通过后允许引用R0相同配置，同时增加完整训练数据上的RF和XGBoost调参。

## 预定预算与候选

每轮48–72小时上限，最多12个筛选配置。固定筛选seed20260922；接受改进前补20260923与20260924。验证全部142轴主指标选点；原log-MAE退步不得超过2%，主指标相对较强调参树基线改善至少5%，并检查食品组配对区间。

| 组 | 候选 | 控制 |
|---|---|---|
| V9时长 | 8、20 epoch，amount=1，source=1 | 同一次20-epoch训练的前8轮和前20轮最佳检查点；固定20轮cosine日程 |
| V9 amount | 20 epoch，amount=2、3 | 其余与amount=1一致 |
| V9来源 | 20 epoch，source=0 | amount=1；损失除以1+source_weight保持整体尺度 |
| 直接回归MLP | 8、20 epoch | 同样任务及固定20轮学习率日程；作为简单结构对照，不将差异归因于损失单因素 |
| RF | 400树/不限深度/leaf1；400树/深24/leaf3 | 全量合格训练行，同一32维名称缓存，max_features=.5 |
| XGBoost | 500树/深8/lr.05；1000树/深6/lr.03；800树/深10/lr.03 | 全量训练数据，其他参数与R0相同 |

V9学习率1e-4、batch64；MLP学习率1e-3、batch256；相同模型的对照不改优化器、初始化、数据顺序或LR日程。过拟合诊断后同时恢复参数和随机状态。8轮与20轮比较表示同一固定日程下的训练预算差异，并非分别调整日程的两次训练。

## 记录要求

每个运行保存源码快照、配置/哈希、逐epoch曲线、最好检查点、8/20轮边界检查点和最后优化器状态。训练期间只读验证；测试保持关闭。完成本轮后 README 必须包括所有候选、原有与新增树基线、name-only与检索跟踪、分轴/来源/正值/零值结果、归因限制、版本决定及下一轮最小实验。

若模型仍落后，不修改评分指标或削弱树模型。根据学习曲线决定是否进入输出目标R2；未得到三种子支持时只记录探索结果。
