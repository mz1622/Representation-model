## 6. 因果分析

**已观察事实：** 两个预登记干预均改善弱父的名称预测/若干检索指标，却显著损害主要补全指标；比强树和名称KNN仍差。输入mask变化以外，监督、参数架构、初始化、任务顺序、优化配置与固定评价受控；完整源码、数据和重放验收通过。

**对照支持的解释：** 在这些固定条件及单种子下，额外删除上下文这一训练分布干预引起了可重复审计的任务取舍，较强删除的补全代价更大。监督量下降、额外标签暴露、改评分或挑弱参照不能解释结果，因为这些项未改变。

**仍未排除的解释：** 训练信息量减少、随机mask模式、自动出现的全空任务、优化困难和有效梯度变化共同发生；不能单独归因为“正则化过强”或“名字被迫使用”。较长训练、其他概率/日程、模型容量可能产生不同结果，但没有本轮证据支持任一解法。原始单位问题、未确认近重复食品、来源格式、单种子及重复验证选择偏差仍存在。不能因稀疏轴某些改善就宣称轴平衡采样必然有用。
