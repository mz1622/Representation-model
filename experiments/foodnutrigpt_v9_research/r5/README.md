## 1. 研究问题与预先假设

相同营养输入与冻结名称空间下，非线性映射是否优于线性Ridge？同一MLP由向量MSE换为名称匹配对比损失，能否改善训练未见名称排序？独立检索作为后续联合训练前的可检验问题，不预设它能改善补全。方案[PLAN.md](PLAN.md)，预登记`4c64bee`。

## 2. 父版本与改动

R0参照为`retrieval_ridge_v1`和`retrieval_name_mlp_v1`。输入仅142营养scaled-log值与142观测标记；候选名称仅看original_name，沿用MiniLM固定修订和训练拟合PCA32。Ridge alpha1复用，新增0.1/10/100。非线性284→512→512→32与线性容量不同，因此两者比较只能归因于完整模型类别干预；MSE/对比两神经臂则保持结构、初始化和日程一致，单改目标。

训练前发现222个既有候选组含大小写/空格变体，于`65955c5`补充保守负例规则：精确同名共享正例列；同一候选组其他名称不作负例，但不当作额外正例、不合并营养值或食品身份。没有模糊别名合并。原严格名称评价保持不变，限制明确保留。
