## 6. 因果分析

**已观察事实：** 固定这一种子和训练预算，将损失改为MAE后，所选检查点的总体误差降低，零值改善而正值退步；与树基线的差距仍显著。

**对照支持的解释：** 损失函数确实影响了零值/正值间的预测取舍。预登记中“损失目标不匹配是部分瓶颈”的解释在这个MLP实验中获得初步支持；不能由此证明它是Transformer的主要瓶颈。

宽度对照支持“增加容量在这套固定训练设置下改善补全”的初步解释，且改善了正值；但它没有同时改善名称检索。不能用较低name-only逐轴误差推导出名称排序更好，排序取决于候选间的细微差异与整体几何。这里的检索解释仍需专项对照，不作因果定论。

固定日程的20/60预算对照支持额外训练改善这个MLP的补全，且主要改善正值。但最佳点在58轮、末几轮收益趋小，不能外推“继续延长必然达到门槛”；name-only主指标没有获得稳定收益。归一化消融用于检验另一个拟合设计假设，不把训练/验证差距直接当作其有效的证据。

**尚未排除：** 种子敏感性、验证选点偏差、残余数据问题、模型容量和优化不足、模型依赖观察模式等。上述单种子比较不支持基础模型、跨来源迁移或真实营养标签可靠性的结论。梯度余弦诊断不构成任务干扰的因果证据。
