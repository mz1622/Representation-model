# R9 MAE 来源校准参数稳定性：只读诊断

[English](REPORT_EN.md) · [机器结果](summary.json)。这是完成MAE复验后的参数诊断，不是新训练版本或校准消融。

## 1. 问题与假设

三个MAE种子的补全误差不同。检查已学习的来源偏置是否整体不稳定，为之后可能的来源校准消融提供描述性线索。参数稳定性并不是校准有效性的充分条件，也不是预测稳定性的替代指标。

## 2. 父模型与控制

只读取已独立审计的种子20260922/23/24检查点，分别由补全选中第60/60/57轮。比较的是所选模型，不是三个同轮次状态。当前MSE训练与文件没有被读取、修改或重启；数据和树基线未改动。

## 3. 方法与可复现信息

CPU单线程，用`weights_only=True`读取源残差参数及24个训练来源索引；依据原实现在每轴对这24个来源作算术均值中心化。没有模型前向、优化、原始营养值或验证标签读取。仅从冻结轴元数据读取名称、家族、监督标记和训练支持数；检查187监督轴、65上下文轴以及全部输入哈希。

偏置单位是缩放log空间，不能当作g/100g。每个统计对24个来源参数等权，不代表按各来源实际观测覆盖加权的预测影响。报告每轴RMS、平均绝对值与最大绝对值；全表相关系数也可能被少量大偏置主导。

```powershell
.venv/Scripts/python.exe scripts/diagnose_foodnutrigpt_r9_calibration_stability.py --output-dir reports/v9_r9_mae_calibration_stability_v1
```

既有目录拒绝覆盖。完整脚本、三个模型、审计和轴元数据指纹见summary.json。未保存或公开完整来源×轴参数矩阵。

## 5. 机制诊断

营养轴偏置整体方向相近，但差的RMS约为偏置自身RMS的24%–27%，不能称为完全相同。以三种子平均每轴RMS计算，最大三个轴为Pentadecenoic acid (15:1; isomer unspecified) 0.289481、Carotene beta 0.258942和Folic acid 0.222293。氨基酸家族的平均每轴RMS为0.015911；这些参数幅度不等于其对主误差的贡献。

## 6. 因果解释与替代解释

观察到的是相关参数结构，而不是开关校准后的性能效应。即使来源偏置稳定，它仍可能有帮助、有害或无明显作用；来源间监督覆盖、主干与残差共同适配、不同所选轮次和验证选择均未被此诊断控制。不能由三个RMS值与三个误差的排序建立因果关系，也不按这些参数给数据库质量排名。

## 7. 决定

不改变正在运行的MSE方案。现有证据不支持把种子差异简单解释为来源偏置方向随机翻转，也不能免除来源关闭的独立验证。MAE配方未确认优于RF的原结论保持不变。

## 8. 下一步与测试状态

先完成已登记MSE对照。之后若选择校准开关实验，应保持`(L_base+lambda*L_cal)/(1+lambda)`的归一形式，单独登记lambda变化，避免同时改损失、容量和优化器。此处未登记或启动该实验；完整测试继续关闭。
